# スマスキャン

スマホのカメラでQRコードを読み取り、そのURLをPCのブラウザで開きます。スマホとPCは同じネットワークに接続してください。

画面はリポジトリ直下の `src/`、APIは `backend/`、起動用スクリプトは `scripts/` にあります。

## 起動

1. `./scripts/setup-certs.sh` でHTTPS証明書を作成します。`mkcert` が必要です。スマホにも表示される手順に従ってローカルCA証明書を信頼させてください。
2. `./scripts/start.sh` を実行します。Dockerとホスト側のPython `requests` パッケージが必要です。
3. 起動画面に表示された `https://<PCのIP>:3002/#token=<接続コード>` をスマホで開き、カメラを許可します。通常のURLで開いた場合は接続コードを入力します。

QRコードを読むとカメラが止まります。PCのブラウザ起動結果が画面に表示されます。続けて読む場合は「次のQRコードを読み取る」を押してください。終了時は起動したターミナルで Ctrl+C を押します。

接続コードは起動ごとに変わります。URLの `#token=` はページ読み込み時に取り除き、コードはその端末のブラウザに保存します。LAN内の他の人に接続コードを共有しないでください。
